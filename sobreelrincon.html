Sobre el Rincón

Un poco más acerca de este pequeño espacio

¿Qué es Rincón Interactivo?

El Rincón Interactivo es una página web interactiva de entretenimiento y exploración digital, donde se reúnen diferentes espacios, contenidos y otros elementos interactivos. Además, incluye una historia ARG experimental que conecta algunas partes de la página. El Rincón Interactivo es un pequeño espacio creado para reunir diferentes cosas que me gustan y convertirlas en una página que se pueda recorrer y descubrir. Aquí hay entretenimiento, música, imágenes, juegos, referencias a películas y otros contenidos que forman parte de mis intereses. También cuenta con la experimental que se va conectando con ciertos elementos del sitio.



¿Cómo surgió la idea?

La inspiración viene de las páginas personales de internet de los años 2000, los sitios de Neocities, los GIF animados, las interfaces antiguas de computadora y distintas estéticas digitales como el dreamcore, el webcore y los espacios liminales. Me gusta esa sensación de encontrar una página que parece tener su propio mundo, donde puedes pasar de una colección de imágenes a una habitación, una computadora o algún sitio inesperado. Por eso, este proyecto busca recuperar un poco de esa libertad y creatividad que tenían las páginas personales, pero agregando ideas propias.



¿Qué puedes encontrar aquí?

  • ARG Experimental: una experiencia que combina exploración y elementos por descubrir.
  • Web Interactiva: Información sobre que es una Web interactiva y funciones con las que puedes interactuar.
  • La Cabaña: un pequeño espacio dividido en 3 diferentes habitaciones.
  • Explorar: La parte del ARG Experimental, un lugar para recorrer y encontrar cosas que no necesariamente están a simple vista.
  • Computadora: una sección inspirada en los escritorios y programas de las computadoras antiguas.
  • Cine y TV: películas, series y otros contenidos relacionados con el entretenimiento.
  • Playlist: música y canciones que forman parte de este rincón.
  • Sitios: una recopilación de páginas interesantes para visitar.
  • Y Ahora: La parte que conecta el final del ARG.
  • Galería General: GIF, imágenes, audios y videos y otras colecciones visuales.

Diseño y créditos

El diseño de este sitio está inspirado en las páginas personales de internet de los años 2000, combinando diferentes estilos, colores, GIF animados, imágenes y elementos decorativos. La intención es que cada sección tenga una apariencia propia y conserve la esencia experimental del proyecto.

Diseño y apariencia del sitio.

Herramientas utilizadas

Para la creación del sitio se utilizan HTML para organizar el contenido, CSS para los estilos y el diseño visual, y JavaScript para agregar funciones e interacciones.

Parte del código utilizado en el proyecto.

Fuentes tipográficas

Se utilizan diferentes tipografías para los títulos como Princes Sofia, Caveat, Coming Soon y elementos decorativos, estas provienen de Google Fonts y fueron seleccionadas según la apariencia que se busca en cada sección para que se vea mas con la vibra del Rincón.

Algunas de las fuentes utilizadas.

Imágenes y elementos gráficos

La página contiene imágenes, GIF, iconos, fondos, texturas y otros recursos visuales. Algunos elementos son de creación propia y otros pertenecen a sus respectivos autores.

Imágenes y elementos decorativos del sitio.

Derechos de autor

Los recursos que no son de mi autoría pertenecen a sus respectivos creadores, obviamente, se reconoce y respeta el trabajo de sus autores y los derechos correspondientes de cada imagen, fuente, GIF y demás elementos usados.
